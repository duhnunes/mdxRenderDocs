Para começar a usar o mdxRenderDocs, instale as dependências principais:

```Terminal
gh repo clone duhnunes/mdxRenderDocs
code mdxRenderDoc
pnpm install
pnpm run dev
```

# Fluxo de pastas

> Funcionamento principal está dentro de `app/docs/`

- `(canary)` - Pasta onde você organiza suas categorias e conteúdos em desenvolvimento.
- `(versioned)` - Pasta onde você organiza suas versões, atual e current.
